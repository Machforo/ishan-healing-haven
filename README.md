# Ishan Ayurvedic Hospital
#################################

Advanced Ayurvedic care and holistic healing in Greater Noida. This project is the official website for Ishan Ayurvedic Hospital, offering insights into treatments, departments, and expert Ayurvedic doctors.

## Features

- **Authentic Panchkarma**: Holistic detox and rejuvenation therapies.
- **Expert Doctors**: Qualified MD/MS Ayurvedic practitioners.
- **Specialized Departments**: Including Kayachikitsa, Shalya Tantra, Prasuti Tantra, and more.
- **Modern Diagnostics**: Integrated pathology and diagnostic services.
- **Patient-Centric Services**: Online consultations and appointment booking.

## Tech Stack

- **Framework**: React with Vite
- **Styling**: Tailwind CSS
- **Components**: Radix UI / Shadcn UI
- **Animations**: Custom ScrollReveal and Tailwind Animate

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
